# BevQuery marketing site

A framework-free static site for GitHub Pages.

## Files
- `index.html` — homepage
- `styles.css` — shared design and responsive styling
- `contact.html` — contact and access request page
- `privacy.html` — working privacy-policy draft
- `terms.html` — working terms draft
- `images/` — logo and real BevQuery screenshots

## Publish on GitHub Pages
1. Upload all files and the `images` folder to the repository root.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the appropriate branch (usually `main`) and `/ (root)`.
5. Save and wait for the temporary GitHub Pages URL.

## Before launch
- Confirm the application login URL in every `https://bevquery.github.io/bevquery-app/` link.
- Confirm `support@bevquery.com`.
- Review the Terms and Privacy Policy against your finalized legal drafts.
- Add a `CNAME` file containing `bevquery.com` only when you are ready to connect the domain.
- Replace or refine `images/logo.svg` as desired.

## Editing copy
Search the HTML files for the visible sentence you want to change. There is no build step.
